# EP Training Map — public edition

A public map of upcoming Election Protection volunteer trainings, by state, for
coalition information sharing.

**Live map:** https://common-cause.github.io/ep-training-map-public/

> For coalition information sharing only. If you're a volunteer and want to sign
> up, go to [protectthevote.net](https://protectthevote.net).

## How it works

- The site is rebuilt every night from the same data behind Common Cause's staff
  training map. Only public fields are published: training details, the city
  for in-person sessions, and registration links.
- The built site lives on the `gh-pages` branch. That branch is **regenerated
  from scratch on every update** as a single commit, so it has no meaningful
  history. Don't open pull requests against it.
- `main` holds this documentation and the embed instructions
  (`docs/wordpress_embed.md`).

Maintained by Common Cause.
